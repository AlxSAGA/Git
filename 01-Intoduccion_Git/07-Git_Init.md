# Comandos básicos de Git:

**Iniciando Repo**

| Comando        | Explicación                                                                                                                                              | Sintaxis y Ejemplos                              |
| :------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------- | :----------------------------------------------- |
| **`git init`** | Inicializa un nuevo **repositorio de Git** en el directorio actual.<br>Crea la carpeta oculta `.git` donde se almacena toda la historia y configuración. | `git init`<br>`git init <nombre-del-directorio>` |
Una ves iniciado usarmos la rama **Main**
```bash
git branch -M main
```
