# GitHub - La Plataforma de Desarrollo Colaborativo
**GitHub** es una plataforma de **alojamiento y colaboración** para proyectos que usan Git. Es como una **red social para desarrolladores** donde se almacena código, se colabora en proyectos y se construye software en comunidad.
#### GitHub vs Git - La Diferencia

| **Git**                                     | **GitHub**                    |
| ------------------------------------------- | ----------------------------- |
| **Sistema de control de versiones** (local) | **Plataforma web** (remota)   |
| Herramienta de línea de comandos            | Interfaz web y colaborativa   |
| Gestiona historial de cambios               | Aloja repositorios en la nube |
| Trabajas localmente                         | Compartes código globalmente  |

#### Funciones Principales
##### Alojamiento de Repositorios
- almacena tu código en la nube
- acceso desde cualquier lugar
- copias de seguridad automáticas
##### Colaboración
- **Pull Requests**: solicitudes de cambios
- **Issues**: seguimiento de bugs y features
- **Discussions**: foros de debate
- **Projects**: tableros Kanban
##### Integraciones
- **GitHub Actions**: CI/CD automático
- **GitHub Pages**: hosting estático gratis
- **Code Scanning**: seguridad del código
- **Packages**: registro de paquetes
##### 🌐 Comunidad
- **Stars**: like a repositorios
- **Forks**: copias de proyectos
- **Followers**: seguidores de tu perfil
- **Trending**: repositorios populares
##### Para Desarrolladores
- Portafolio de proyectos
- Contribuir a open source
- Aprender de otros código
- Networking profesional
##### Para Empresas
- Gestión de proyectos
- Trabajo en equipo remoto
- DevOps automatizado
- Reclutamiento de talento
##### Free (Gratis)
- Repositorios públicos ilimitados
- Repositorios privados (límite de colaboradores)
- GitHub Pages
- GitHub Actions (minutos limitados)
##### Team ($4/usuario/mes)
- Repositorios privados ilimitados
- Environments protegidos
- Pages privadas
- Soporte prioritario
#### Alternativas a GitHub

| Plataforma       | Ventajas                                    |
| ---------------- | ------------------------------------------- |
| **GitLab**       | CI/CD integrado, más features gratis        |
| **Bitbucket**    | Integración con Jira, repos privados gratis |
| **Azure DevOps** | Ecosistema Microsoft, enterprise            |
| **SourceForge**  | Open source tradicional, más antiguo        |
#### Interfaz Grafica Github Explicación de las Pestañas de un Repositorio en GitHub
##### Code (`/`)
- **Código fuente** del proyecto
- Archivos, carpetas y estructura
- Ramas, tags y releases
- **README.md** (documentación principal)
##### Issues (`/issues`)
- **Seguimiento de bugs** y errores
- **Solicitud de nuevas features**
- **Tareas pendientes**
- Sistema de etiquetas, asignaciones y milestones
##### Pull Requests (`/pulls`)
- **Solicitudes de cambios** (merge)
- **Code review** y discusión de código
- **Integración de contribuciones**
- **Checks automáticos** (CI/CD)
##### Discussions (`/discussions`)
- **Foro de debate** comunitario
- Preguntas y respuestas (Q&A)
- Anuncios y discusiones generales
- **No es para bugs** (eso es para Issues)
##### Actions (`/actions`)
- **CI/CD Automatizado** (GitHub Actions)
- **Flujos de trabajo** automáticos
- Tests, builds y deployments
- **Integración continua**
##### Projects (`/projects`)
- **Tableros Kanban** para organización
- **Gestión de proyectos** visual
- Seguimiento de tareas e issues
- **Roadmaps** y planificación
##### Wiki (`/wiki`)
- **Documentación** extensa del proyecto
- Guías, tutoriales y how-tos
- **Knowledge base** colaborativa
- Información técnica detallada
##### Security (`/security`)
- **Reportar vulnerabilidades**
- **Security advisories**
- **Dependabot alerts** (dependencias vulnerables)
- **Code scanning** resultados
##### Insights (`/insights`)
- **Métricas** y analytics del repositorio
- **Traffic**: visitas y clones
- **Contributors**: actividad de colaboradores
- **Community**: standards de comunidad

#### Flujo de Trabajo Típico
1. **Code**: Escribir código
2. **Issues**: Reportar bugs/sugerencias  
3. **Pull Requests**: Proponer cambios
4. **Actions**: Tests automáticos
5. **Projects**: Organizar trabajo
6. **Wiki**: Documentar
7. **Security**: Mantener seguro
8. **Insights**: Analizar progreso
