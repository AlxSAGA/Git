# Crear una Cuenta en GitHub

#### Preparación Previa
- **Tener un email válido** (no temporal)
- **Elegir una contraseña segura**
- **Pensar un nombre de usuario** (¡importante!)
---
#### Pasos para Registrarse
##### 1. Acceder al sitio oficial
👉 **[github.com](https://github.com/)**
##### 2. Completar formulario de registro
```txt
Username: [tu_nombre_de_usuario]
Email: [tu_email@ejemplo.com]  
Password: [tu_contraseña_segura]
```
##### 3. Verificar email
- Revisar tu bandeja de entrada
- Buscar email de GitHub
- Hacer clic en enlace de verificación
##### 4. Completar configuración inicial
- **Tipo de cuenta**: Personal o Profesional
- **Intereses**: Student, Teacher, Open Source, etc.
- **Preferencias**: Notificaciones y privacidad
##### 5. Plan elegir (¡Gratis para empezar!)
- **Free**: Para la mayoría de usuarios
- **Pro/Team**: Si necesitas features avanzadas

**Seguridad**
```txt
# Habilitar verificación en dos pasos (2FA)
Settings → Security → Two-factor authentication
```

**Perfil publico**
```txt
# Completar perfil profesional
Settings → Profile → 
  - Name
  - Bio
  - Avatar
  - URL personal
  - Company
```

#### 1. Crear tu primer repositorio
- **New Repository**
- **Nombre**: `hola-mundo`
- **Descripción**: Mi primer repositorio
- **Visibilidad**: Público o Privado
- **Initialize with README** ( Opcional )
1. **Verificar email**
2. **Habilitar 2FA** (Authenticator app)
3. **Revisar sesiones activas**
4. **Generar tokens de acceso** (en vez de passwords)
